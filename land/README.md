# 土地分割シミュレーター

土地の図面や写真を取り込み、**実寸に合わせてから 50cm グリッドで分割する**ためのページ。
面積・辺の長さ・区画ごとの価格がその場で出る。スマホの指だけで完結する。

`land/index.html` を開くだけで動く。サーバもビルドも要らない。

## 使い方

### 1. 寸法モード — 画像を実寸に合わせる

1. **画像を取り込む**（メニュー、またはドラッグ＆ドロップ、貼り付け）。
   測量図・公図・現況図・マイソクなど、土地の形が分かるものなら何でもいい。
2. **基準線**で、長さの分かっている辺（間口など）をなぞる。
3. 出てきた欄に**実際の長さ**（例: 12m）を入れる。

これで画像全体の縮尺が決まる。「グリッドに合わせる」を入れたままにしておくと、
その線が水平（または垂直）に倒れ、始点が格子の交点に載る。
**つまり、なぞった辺がそのままグリッドの何マスかに一致する。**

合わせきれないときは「微調整」で回転・大きさ・位置を動かす。
基準線の始点を軸に動くので、合わせた点はずれない。

### 2. 分割モード — 50cm グリッドで切る

- 「描き込む先」で **敷地** か **区画** を選び、画面をなぞる。
  なぞった四角が **50cm 単位に吸着して**足される。斜めの線は原理的に引けない。
- 何回か足せば L 字や旗竿もそのまま作れる。行き過ぎたら「消す」で削る。
- 区画どうしは重ならない。あとから引いたほうが取る。
- 面積（㎡・坪）、外形の寸法、外周の各辺の長さは自動で出る。

### 3. 価格 — 総額を面積で割り戻す

- **全体価格**（万円）を入れると、区画ごとの価格と坪単価が出る。
- 区画には**地型**（整形地・旗竿地など。増やせる）を割り当てる。
- **ケース**ごとに地型の係数を持てる。旗竿地を 0.7 にすれば、その分だけ整形地の坪単価が上がる。
  **配り方が変わるだけで、合計は必ず全体価格に一致する。**
- ケースは何組でも作れるので、「旗竿 0.7 の場合」「0.6 の場合」を並べて比べられる。

割り戻しの分母は**区画の合計面積**。道路やのりばを区画にしていない場合、
その分は配分されない（パネルにその旨が出る）。

### そのほか

| したいこと | やり方 |
|---|---|
| 拡大・移動 | 指2本でピンチ／マウスはホイールと右ドラッグ。「表示を動かす」でも可 |
| 案を並べる | 「案」の＋新規・複製。画像と敷地は全部の案で共通 |
| 長さを測る | 「計測」で2点をなぞる。分割モードでは格子点に吸着する |
| 図を渡す | メニュー →「図を画像で書き出す」（凡例つき PNG） |
| 数字を渡す | メニュー →「面積の一覧をコピーする」（タブ区切り。表計算にそのまま貼れる） |

データは**その端末の中だけ**に保存される（localStorage）。サーバへは何も送らない。
画像は長辺 2000px に縮めて持つ。

## 作りの要点

- ワールド座標は**メートル**。画面はそこへの平行移動と一様拡大でしか写さない（画面は回らない）。
- 区画は多角形ではなく **50cm セルの集合**で持つ。
  だから斜めの線が生まれず、面積は数え上げるだけで厳密に出る。外周の辺も集合から導く。
- 傾いているのは**画像のほう**。画像を回してグリッドに合わせるので、分割側は何も考えずに済む。

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の骨組みとアイコン |
| `land.css` | 見た目。色は `../tokens.css` の変数を経由する |
| `land.js` | 全部。セル／描画／操作／価格／保存 |

## 1枚にまとめて配る

```bash
node tools/build_land.js dist/land.html
```

`../tokens.css` も含めて 1 ファイルにする。メールでもチャットでもそのまま渡せる。

## テスト

```bash
node tools/test_land.js
```

実際の Chromium で、画像の取り込み → 基準線 → 分割 → 価格の按分 → 書き出し → 再読み込みまでを通す。
`playwright` が無いときは何もせず終わる。
